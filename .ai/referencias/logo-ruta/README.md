# fluyo-logo-ruta

Paquete de referencias del logo Ruta para el PO y Claude Code.

1. Copia esta carpeta al repo de FLUYO como `.ai/referencias/logo-ruta/`.
2. Envía `PROMPT-PARA-EL-PO.md` al PO.
3. El PO aprueba y le pasa a Claude Code su prompt, apuntando a esta carpeta (`INSTRUCCIONES-PARA-CODE.md` primero).
